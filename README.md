# A Children’s Playground

Standalone book website by Umar Rafi.

Production: `main`. Development previews: `book-dev`.

Static HTML site: no build command; output directory is repository root (`/`).

Cloudflare Pages project: achildrensplayground. Set main as production branch and book-dev as a preview branch. Add www.achildrensplayground.com and achildrensplayground.com as custom domains; redirect the root hostname to www.

Author website: https://www.umarrafi.com/
